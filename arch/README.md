# Arch desktop theme

**AMBER-76**: warm text (`#e8dcc0`) and amber (`#ffb000`) on charcoal
(`#1c1b19`), with square edges, Terminess Nerd Font, and little motion.

Themes tmux, Kitty, Rofi, Dunst, GTK, Zathura, btop, Fastfetch, Fcitx5, Azote,
and Xresources, plus wallpapers. [i3 Amber](../i3/amber/) builds on it.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- arch "$HOME"
```

Install the apps and the font separately.

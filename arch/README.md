# Arch desktop theme

AMBER-76: charcoal (`#1c1b19`), warm text (`#e8dcc0`), amber (`#ffb000`), orange (`#e8742c`), and teal (`#3e9d9a`). Terminess Nerd Font, square edges, and little visual motion. The files cover tmux, Kitty, Rofi, Dunst, GTK, Zathura, btop, Fastfetch, Fcitx5, Azote, Xresources, and wallpapers.

## Install

The final path is the home root. Install the matching applications and font separately. The [Amber i3 setup](../i3/amber/) installs this theme too.

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- arch "$HOME"
```

The old [arch.config](https://github.com/chaseungjoon/arch.config) retains the full machine migration snapshot. This repo keeps its desktop styling only.

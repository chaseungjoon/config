# Arch desktop theme

**AMBER-76** pairs charcoal (`#1c1b19`) with warm text (`#e8dcc0`) and amber
(`#ffb000`). Square edges, Terminess Nerd Font, and little motion.

Includes tmux, Kitty, Rofi, Dunst, GTK, Zathura, btop, Fastfetch, Fcitx5,
Azote, Xresources, and wallpapers.

## Install

The last path is a home directory. Install the apps and font separately.
[Amber i3](../i3/amber/) includes this theme.

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- arch "$HOME"
```

The original [arch.config](https://github.com/chaseungjoon/arch.config) keeps the
machine migration snapshot.

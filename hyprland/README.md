# Hyprland

An independent Hyprland setup.

| | [Mocha](mocha/) |
| --- | --- |
| **Focus** | Rounded glass and laptop controls |
| **Bar** | Waybar, 40 px, with Rofi menus |
| **Compositor** | Hyprland (blur, spring animations) |
| **Terminal** | Kitty |
| **Font** | JetBrainsMono Nerd Font |
| **Palette** | Blue `#89b4fa` and mauve `#cba6f7` on Mocha `#1e1e2e` |
| **Includes** | Its own Waybar, Rofi, Kitty, SwayOSD, and Waypaper |

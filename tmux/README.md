# tmux

Transparent, plugin-free theme. `Ctrl+s` is the prefix; `h/j/k/l` move between panes, `r` reloads the config. Mouse, clipboard, and one-based indexes are enabled.

## Install

Change the final path to choose the config file.

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- tmux "$HOME/.tmux.conf"
```

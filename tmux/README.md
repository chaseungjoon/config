# tmux

Transparent, plugin-free, with the status bar at the top.

- Prefix: `Ctrl+s`; reload: prefix then `r`.
- Panes: prefix then `h` / `j` / `k` / `l`.
- Mouse, clipboard, and one-based indexes enabled.

![tmux status bar](https://github.com/user-attachments/assets/d9364051-f769-4e2d-aa53-c18f091c58aa)

## Install

Change the last path to choose the config file.

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- tmux "$HOME/.tmux.conf"
```

Original repository: [tmux.config](https://github.com/chaseungjoon/tmux.config).

# tmux

Transparent, plugin-free tmux with the status bar at the top.

![tmux status bar](https://github.com/user-attachments/assets/d9364051-f769-4e2d-aa53-c18f091c58aa)

| Key | Action |
| --- | --- |
| `Ctrl+S` | Prefix |
| prefix, `r` | Reload config |
| prefix, `h/j/k/l` | Move between panes |

Mouse and system clipboard are on, and windows and panes count from 1.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/chaseungjoon/config/main/install.sh | bash -s -- tmux "$HOME/.tmux.conf"
```

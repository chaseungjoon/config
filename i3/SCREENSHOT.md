# Amber screenshots

Capture the Amber desktop at its native resolution:

1. Open a terminal and Rofi, with the i3blocks bar visible. Hide private window titles, usernames, network names, and notifications.
2. Capture the desktop as `amber-desktop.png`. Capture a second image focused on the bar as `amber-bar.png`.
3. Put both files in `i3/screenshots/`. Check the images for private information before committing.
4. Replace the placeholder image link in `i3/README.md` with `screenshots/amber-desktop.png`; add the bar image to `i3/amber/README.md`.

Use `Print` for a full screenshot or the existing `~/.config/i3/scripts/screenshot` script. Keep the images unedited except to crop or redact private details.
